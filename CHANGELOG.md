# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-06-16

### Added

- Initial release of the Kinaxis Maestro MCP server.
- MCP tools for health checks, table discovery, query execution, paginated result retrieval, and query cleanup.
- Bulk export and bulk upload workflows for larger Kinaxis data operations.
- Workbook, script, and workflow tools for broader Maestro automation coverage.
- OAuth2 client-credentials and Basic Auth support for Kinaxis authentication.
